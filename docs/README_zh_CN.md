# DeathRollback

**DeathRollback** 是一个 Minecraft 生存/极限辅助 Mod，它可以帮助你在生命值降低时创建备份，并在死亡时回滚。

## 兼容性

DeathRollback 只支持 Fabric 加载器，目前仅能保证 1.21/1.21.1 可用，更多版本已在开发计划中。
